# Infinity Ball

Infinity Ball is a web-based multiplayer game set in a visually infinite space. Control a glowing ball, place marks, teleport, and use power-ups. Supports up to 4 controllers/players.

## Features

- Multiplayer support (up to 4 controllers)
- Interactive gameplay with ball movement, marks, teleportation, and power-ups
- Multiple camera modes (follow, first-person, free, cinematic)
- Ball trail and infinity space effects
- Mini-map and replay/recording system
- Sound effects and color themes
- MIT License

## Getting Started

1. Clone the repository:
   ```
   git clone https://github.com/asifff113/infinityball.git
   ```
2. Open `index.html` in your browser to play.
3. Make sure you have an internet connection (Three.js loads via CDN).

## Game Objective

Navigate your ball through an infinite grid space, place marks, teleport, and collect power-ups. Compete or cooperate with up to 4 players/controllers.

## Rules

- Move your ball using keyboard controls.
- Place marks to track your path or set waypoints.
- Teleport to marks using the teleport feature.
- Use power-ups for temporary advantages (speed, size, invincibility).
- Record and replay your movement for analysis or fun.

## Controller Setup

Infinity Ball is designed for keyboard play. Each player can use a separate keyboard or configure external controllers mapped to the same keys. (Gamepad support can be added in future updates.)

## Controls

See the in-game controls panel for a full list. Key highlights:

- **W/A/S/D or Arrow Keys**: Move ball
- **Space**: Move up
- **Shift**: Speed boost / Move down
- **M**: Place mark
- **R/Delete**: Remove nearest mark
- **T + 1-9**: Teleport to mark
- **T (double-tap)**: Toggle teleport feature
- **C**: Cycle camera mode
- **V**: Toggle mini-map
- **B**: Start/stop recording
- **X**: Toggle recording feature
- **N**: Toggle replay
- **1-4**: Change mark type
- **5-8**: Change theme
- **9**: Size power-up
- **0**: Speed power-up
