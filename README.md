# Infinity Ball

A web-based game project supporting up to 4 controllers. This repository contains the main HTML and JavaScript files for the game.

## Features
- Multiplayer support (up to 4 controllers)
- Interactive gameplay
- MIT License

## Getting Started
1. Clone the repository:
   ```
   git clone https://github.com/asifff113/infinityball.git
   ```
2. Open `index.html` in your browser to play.
