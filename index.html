🎮 Controls

  • W / ↑ - Move Forward
  • S / ↓ - Move Backward
  • A / ← - Move Left
  • D / → - Move Right
  • Space - Move Up
  • Shift - Speed Boost / Move Down
  • M - Place Mark
  • R / Delete - Remove Nearest Mark
  • T + 1-9 - Teleport to Mark
  • T (double-tap) - Toggle Teleport Feature
  • C - Cycle Camera Mode
  • V - Toggle Mini-map
  • B - Start/Stop Recording
  • X - Toggle Recording Feature
  • N - Toggle Replay
  • 1-4 - Change Mark Type
  • 5-8 - Change Theme
  • 9 - Size Power-up
  • 0 - Speed Power-up
